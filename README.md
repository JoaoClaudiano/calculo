# CalculusVision Pro

Ferramenta educacional visual para cálculo diferencial e integral com recursos pedagógicos avançados.

## 🚀 Funcionalidades

- 📊 Plotagem de funções matemáticas
- 🔢 Cálculo de derivadas e integrais
- 📈 Análise de limites
- 👨‍🏫 Modos Professor/Aluno
- 📝 Exercícios guiados
- 💾 Histórico de cálculos
- 📱 Design responsivo
- 🔧 Instalação como PWA

## 🛠️ Tecnologias

- HTML5, CSS3, JavaScript
- Plotly.js para gráficos
- Math.js para cálculos
- Tailwind CSS para estilos
- Service Workers para PWA
